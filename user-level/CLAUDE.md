# ~/.claude/CLAUDE.md（ユーザーレベル）

すべてのリポジトリの Claude Code セッションに適用される個人ルールです。

## 基本

- 回答・ドキュメント・コメント・PR 本文は日本語で書く（コード・コマンド・固有名詞は原文のまま）。
- 作業開始時に `git status` とブランチを確認し、未コミットの変更を保護する。
- 不明点は合理的な仮定で進め、重大な仕様矛盾・不可逆操作・課金・権限変更のときだけ質問する。

## 検証

- 変更内容に応じてテスト・型チェック・Lint・ビルド・実動作を確認してから完了とする。
- 検証できなかった項目は「未検証」と理由を明記する。

## Git

- コミット前に差分と秘密情報の混入を確認する。
- 強制プッシュ・履歴改変・保護ルールの回避は行わない。

## 完了報告

1. 実施内容と主な変更ファイル
2. 実行した検証と結果
3. ブランチ・コミット ID・プッシュ／デプロイ状況
4. 未解決事項・未検証項目
